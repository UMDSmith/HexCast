Connect to Discord

HexCast talks to the Discord app running on this machine - no bot, no server changes. Nothing leaves your machine except one token exchange with Discord.

  1. Have the Discord desktop app running and be signed in.
  2. Click Connect below - Discord pops an approval dialog.
  3. Click Authorize in Discord. That's it; the approval is remembered.
  4. Join a voice channel and everyone in it appears below and in the overlay.

Browser source

Add as a Browser source in OBS, sized to taste. Background is transparent. Uncheck "Shutdown source when not visible". Layout options can also be overridden per scene with query params, e.g. ?layout=column&size=96.

Advanced

By default HexCast authorizes as Discord's own StreamKit app, because the rpc scope only works for Discord-approved applications. Only change this if you have an approved app of your own, plus an endpoint that can turn the authorize code into an access token.

Changing the client ID clears the stored authorization - Discord will ask again.
