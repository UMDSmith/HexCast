Settings

Settings for Hexcast as a whole. Each plugin keeps its own settings on its own tab.

Updates

Hexcast can look on GitHub for newer versions of itself and of the modules you have installed, so you see Update to 1.1 without needing git. It asks at most once an hour, in the background, and says nothing when you are offline.

Check GitHub for updates Fetches the VERSION file and the plugin.json of each plugin you installed - nothing about you or your streams is sent. Off = no update requests at all; version numbers still show, and updates from the local catalog/ folder (after a git pull) still work.
