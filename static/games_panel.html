API

Everything a bot needs is plain HTTP; every endpoint returns {"ok": true|false, …}. While a spin is in flight, on screen, or cooling down, new spins get HTTP 409 {"error":"busy","retry_in_ms":…}. Full reference as JSON at GET /games/api.

Bet syntax — American wheel (case-insensitive, spaces ignored; bare lists use / or ,; even money loses on 0 and 00)
