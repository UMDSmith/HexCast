Plugins core

Hexcast is the soundboard plus plugins. Everything else — Twitch, Music, Discord, Clips, Countdown, Games, Ticker — is added from the + tab in the top bar, in a few seconds and with no restart. A plugin appears on this page (with its API) only while it is installed. Removing one keeps its settings, so adding it back later picks up where you left off. Full guide: docs/plugins.md.

GET /api/pluginswhat is installed and what can be installed; ?parent=games lists an add-on family (the games)
GET /api/plugins/navthe tabs of the top bar
POST /api/plugins/{id}/installinstall (and start) a plugin, plus anything it requires → {job}
POST /api/plugins/{id}/updatereplace it with the catalog's newer copy → {job}
POST /api/plugins/{id}/repairre-install its Python packages → {job}
GET /api/plugins/jobs/{job}progress of an install / update / repair: state, lines
POST /api/plugins/{id}/uninstall{"cascade": true} also removes the plugins that need it; settings are kept
POST /api/plugins/{id}/enable · disableturn a plugin on or off without deleting it
GET /api/backgroundsthe shared library of overlay background images (also POST to upload, POST /delete)
