Soundboard core

Trigger media from your library by name — everything a bot, hotkey deck, or channel-point redeem needs is a single GET. Names are the filename without extension, case-insensitive. The overlay applies each clip's saved position, scale, volume, trim and chroma key automatically; query params override them for one play. Chroma keying (Edit Mode → clip → Chroma key: color, 💧 eyedropper, tolerance) removes the green screen per clip inside the overlay, so overlapping clips composite cleanly — drop any chroma filter on the OBS source itself.

GET /api/listevery triggerable name, grouped audio / video
GET /api/play/{name}play by name across both kinds (audio checked first)
GET /api/play/{kind}/{name}same, but explicit — kind is audio or video
GET /api/stopclear all overlay visuals and stop all audio
GET /apithis reference as JSON

Per-play overrides (query params)

?x=50&y=50&scale=2position/size, video only (percent of canvas, scale factor)
?volume=0.50.0–1.0, audio and video-with-audio
?start=2&end=5trim window in seconds (static images use it as display time)

Lock a clip to an avatar

With the Avatars plugin a video or GIF can play glued to a spot on a model - over a head, on a hand - and follow it as it moves, instead of at a fixed place. Lock it on the avatar's Clips tab and anything that plays it gets it locked; or ask for it in one call. It plays on the overlay that shows that avatar (its sound comes out of that overlay's OBS source); if no open overlay shows the avatar it plays here as usual and the answer says "attached": false. Edit Mode keeps a clip's lock when it saves the clip's position.

?avatar=hex&anchor=head_topvideo only: play it on avatar hex, at its pin point head_top (or a spot in its box: &ax=50&ay=20); &dx=0&dy=-40 nudge it (% of the clip's own size), &ascale=0.8 its size, &layer=back behind the model. ?avatar= (empty) plays it here whatever the clip says
POST /attach{"file": "heart.mp4", "kind": "video", "attach": {"avatar": "hex", "anchor": "head_top", "dy": -40}} locks a clip for good; "attach": null lets it go
