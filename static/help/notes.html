Browser notes

Sound in a browser tab

Browsers block unmuted autoplay in normal tabs until you've interacted with the page. If a clip starts silent, the overlay shows a "muted by the browser" pill — one click anywhere fixes the whole tab session. Permanent fix: Firefox — address-bar permissions icon → Autoplay → Allow Audio and Video. Chrome — padlock → Site settings → Sound → Allow (Chrome also learns from regular use). Permissions apply to the whole host and port, every page under it. OBS browser sources allow unmuted autoplay natively and are never affected.

OBS browser sources

For every overlay: uncheck Shutdown source when not visible and Refresh browser when scene becomes active. Overlays reconnect on their own and restyle live when you save settings in a panel. If a re-upload doesn't repaint, right-click the source → Interact → Ctrl+Shift+R.

No authentication

Every endpoint above is open to anyone who can reach the port — that's what makes bots one-line simple. Keep HexCast on a trusted LAN and never expose it to the internet.
