Media cue

Auto-fire a soundboard clip so it ends at a chosen point in the countdown — e.g. intro music that finishes exactly at 0:00. The server reads the clip's (trimmed) length and works backwards to start it on time. Armed when you press Start (or on autostart).

Background

Give the timer a backing panel — solid, gradient, glass, an image, or a 9-slice image frame — or leave it as None for bare digits. Rounded corners apply to every style except the 9-slice frame (which defines its own edges).

Placement

Fixed 1920×1080 stage that scales to fill the browser source, so everything keeps its proportions at any size. The blue box is where the digits & caption sit; the red box places the background — solid, gradient, glass or an image frame (it only shows when a background style is chosen). When an image style is used the red box's width snaps to the image; drag its height. Drag to move, grab a corner to resize.
