Twitch app

Twitch needs its own app registration before it will let HexCast read your events. One-time setup, takes about two minutes.

  1. Go to dev.twitch.tv/console/apps/create
  2. Name it anything. Category: Broadcaster Suite. Client Type: Confidential.
  3. Add this exact OAuth Redirect URL: __REDIRECT_URI__
  4. Create it, then copy the Client ID and generate a Client Secret.

These are stored in config/twitch_secrets.json. HexCast has no login, so keep the port on your LAN only.

Channels

The channels HexCast watches (up to 5). The first is the primary: the chat and alert sources show it unless their URL says otherwise. A channel uses the account with its own name if you have signed in as it - all its alerts, shoutouts as the broadcaster. Otherwise it uses your default account (its chat, and whatever that user may see there as a moderator), or anonymous chat when nobody is signed in.

A source can also choose for itself: add ?channel=name to its URL for one channel, or ?channel=all for every channel. Tick Tag each line with its channel on the Chat tab (Text) to tell merged lines apart.

Sign in

Signing in unlocks follows, subs, gifts, bits, raids and channel point redeems, for the channels that account owns. Without it you still get chat, read anonymously. To add another account, sign in to Twitch as that user in this browser first (a private window works), then connect.

Browser sources

Add each as a Browser source in OBS. Size the source however you want the box to be, then drag it into place. Turn off "Shutdown source when not visible".

Send events elsewhere

Every chat message and alert is POSTed as JSON to this URL. Leave blank to skip. Useful for feeding a bot or a local model.
