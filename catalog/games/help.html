Games /games

Bot-driven games on stream. Each game is an add-on you install from the + inside the Games tab, gets its own tab there, and draws on its own layer of one OBS browser source (/games/overlay, 1920×1080, Control audio via OBS on for the built-in sounds; add ?game=roulette to a source to show just that game). The server picks every outcome with secrets.SystemRandom — the overlay only animates the result and nothing can force one. Hexcast never holds a balance: the channel's bot is the bank, and a numbered, persisted ledger tells it exactly what to take and pay, even across restarts. Every game has its own help page (see Games in the sidebar), and only the games you have installed are listed. All endpoints return {"ok": true/false, ...}.

GET /games/apithis reference as JSON — the installed games and their routes
GET /games/api/registrythe installed games: title, tab order and the scripts their panel and overlay load
GET /games/api/statusconnected overlay count + each installed game's state
GET · POST /games/api/configfull config as JSON · merge-and-save {"<game>": {...}}; a game that is not installed keeps its saved settings for when it comes back
GET|POST /games/api/stopabort every animation and hide everything, stop every countdown; a spin already started still goes into history (and settles the table)
GET /games/api/ledger?since=0&game=the shared ledger: every game's coin movements in one stream, each event with its game; game= for one
GET|POST /games/api/{game}/stop · show · hidethe same actions for one game (hide answers 409 while it is spinning)
WS /games/ws/overlay · /games/ws/panellive config / state / stop / registry messages; panel sockets also get {"type":"ledger","game":...,"events":[...]}

Games are installed one by one from the + inside the Games tab, or from a terminal: python hexcast.py plugins install games_roulette games_craps games_russian games_trivia. Removing one keeps its settings and its table file; bets that are still down come back with it. Launch and landing clips play on the soundboard overlay (/overlay), so keep both browser sources in the scene. Full guide: docs/games.md.
