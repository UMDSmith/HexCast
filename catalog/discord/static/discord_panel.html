Connect to Discord

HexCast talks to the Discord app running on this machine - no bot, no server changes. Nothing leaves your machine except one token exchange with Discord.

  1. Have the Discord desktop app running and be signed in.
  2. Click Connect below - Discord pops an approval dialog.
  3. Click Authorize in Discord. That's it; the approval is remembered.
  4. Join a voice channel and everyone in it appears below and in the overlay.

Browser source

Add as a Browser source in OBS, sized to taste. Background is transparent. Uncheck "Shutdown source when not visible". Layout options can also be overridden per scene with query params, e.g. ?layout=column&size=96.

Advanced

By default HexCast authorizes as Discord's own StreamKit app, because the rpc scope only works for Discord-approved applications. Only change this if you have an approved app of your own, plus an endpoint that can turn the authorize code into an access token.

Changing the client ID clears the stored authorization - Discord will ask again.

Log

Participants

Everyone in your current voice channel. Mode Auto uses uploaded images when they exist and falls back to the Discord avatar. Upload an idle and a talking image (png/gif/webp) for PNGTuber-style reactions - with a full pair the images swap and stay at full brightness (see "Darken idle+talking pairs too" on the Overlay tab); with only an idle image, it brightens while speaking. Picking an image opens a framing tool: drag/zoom the image and choose a circle, rounded, or no outline - or upload it untouched. Animated files (gif/webp/apng) skip the tool and upload as-is so the animation survives. The overlay never crops or rounds uploads on its own, so transparent backgrounds and custom frames show as-is. Size 0 means the overlay default; offsets nudge one person around in pixels.

Layout

Style

Avatar shape only applies to Discord avatars — custom uploaded images always render unclipped at their native aspect ratio, so transparent PNGs, frames, and full-body art show exactly as authored. Default image size applies to anyone without a per-user size on the Participants tab (a per-user size overrides it).

Settings apply live to open overlays. Any of them can be overridden per browser source with query params: ?layout=grid&grid_columns=2&size=160&show_names=0

Placement

Drag people around this preview of your OBS canvas, exactly like positioning a clip in the soundboard editor. Click someone to select them, then use the size slider or scroll over them. Positions are saved per person and used when the overlay arrangement is Free placement; people you haven't placed start at a spot near the bottom centre. Sizes are pixels on a 1920×1080 browser source.
