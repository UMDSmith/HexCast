Placement & live preview

This is the real overlay, live. Drag the dashed box to move the ticker, grab a corner to resize it, or type exact numbers below (bar height is in 1080p pixels). Every setting on this page applies as you change it; there's no Save button for the look.

Ticker

Announce

Send a one-off line. It goes to the announce feed, scrolls next, and drops off after the time you pick (0 = stays until you remove it).

Feeds

A feed is a named list of lines. Enabled feeds scroll in this order, each one led by its label. Lines with a key are unique within their feed, so the bot can update them in place (for example key=alice&value=1300). A line with no text is built from the feed's template, using {key} and {value}. A feed can also pull its lines from a JSON URL. Anything the bot changes shows up here live.

Bar opacity sets how see-through the background is. Ticker opacity fades the whole ticker, text included.

API for bots

Every call works as a plain GET with query parameters, or as a POST with the same fields in JSON. Feed names are 1–40 characters of a–z, 0–9, _ or -. A feed is created the first time something writes to it. Full reference: Help → Ticker.
