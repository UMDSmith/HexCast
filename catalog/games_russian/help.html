Russian Roulette /games#russian

A side-on revolver and a stuffed dummy with a name tag on the games overlay (/games/overlay, or ?game=russian). Pull k loads k bullets and re-spins (chance k/6); chat bets the dummy survives (the stake rides and grows from pull to pull) or goes bang this pull — all against the bank (your bot), through the shared ledger. 30 s to bet, 20 s between pulls, 3 pulls; no bets ends the game. The dummy's dummy_user (the volunteer) gets 5% of the bank's net win. Placement, look and the header's title (title, your branding) live in the Games panel's Edit Mode. Details: docs/russian_roulette.md.

GET|POST /games/api/russian/start{dummy, dummy_user, rounds, seconds, test} — start a game; test writes nothing to the ledger; 409 while one runs
GET|POST /games/api/russian/bet{user, side: survive|bang, amount} → debits, player; 409 bets_closed outside a betting window
GET|POST /games/api/russian/cashout{user} → the survive stake's value now (ledger credit, reason cashout)
GET|POST /games/api/russian/remove{user, side?} — take back what went down in this window (refund)
GET|POST /games/api/russian/dummy{dummy, dummy_user} — before the first pull, or for the next game
GET|POST /games/api/russian/nextend the current phase now (alias /pull)
GET /games/api/russian/table · user/{name} · ledger · history · betsthe STATE · one player · this game's ledger events · finished games + stats · rules + odds
GET|POST /games/api/russian/stopend the game: a pull in progress counts, bang bets refunded, survive stakes cashed out
GET|POST /games/api/russian/preview{overrides, seconds} — Edit Mode's Test in OBS: the scene on screen for a few seconds with that look (STATE.preview); never touches the game · /preview/clear
