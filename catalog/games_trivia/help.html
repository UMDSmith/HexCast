Trivia /games#trivia

A game-show quiz on the games overlay (?game=trivia). Chat bets before each question (only its number, category and difficulty show), then answers A–E; everyone may answer, only bets are paid. Right answers pay ×1.5 / ×2 / ×3 by difficulty, +10% per question won in a row; winners ride or cash out (no choice = cashed out). 15 questions from Open Trivia DB and your own lore questions, never repeated in a night. The board's title (title, "TRIVIA") and the name of your own questions (lore_label, "Channel Lore") are your branding: set them in the Games panel's Edit Mode or Settings. Details: docs/trivia.md.

GET|POST /games/api/trivia/start{questions, difficulty, category, lore, seconds, test} — 409 while one runs, 503 when no question could be had
GET|POST /games/api/trivia/bet{user, amount} — a stake on the next question (ledger debit)
GET|POST /games/api/trivia/answer{user, answer} — A–E, 1–5 or the option text; the last answer counts
GET|POST /games/api/trivia/ride · cashout{user} — let a win ride · take it (credit)
GET|POST /games/api/trivia/nextend the current phase now
GET|POST /games/api/trivia/lore · lore/removeyour own questions: list · add {question, correct, incorrect[], difficulty, category} or {"questions": [...]} · delete {id}
GET /games/api/trivia/bank · categories · POST asked/clearquestion pool + asked list · OpenTDB categories · a new night
GET /games/api/trivia/table · user/{name} · ledger · historythe STATE (the answer only from the reveal on) · one player · ledger events · finished games
GET|POST /games/api/trivia/stopend the game: stakes refunded, winnings cashed out
GET|POST /games/api/trivia/preview{overrides, seconds} — Edit Mode's Test in OBS: the board on screen for a few seconds with that look; never touches the game · /preview/clear
